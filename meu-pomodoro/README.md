# ZenFocus 🧘

Um temporizador Pomodoro com temas visuais imersivos e sons ambientes procedurais.

## ✨ Funcionalidades

- **Timer Pomodoro** com foco e pausa
- **3 temas visuais** com imagens de fundo em alta resolução (Unsplash): Floresta Fria, Fogueira e Nevada
- **Sons ambientes gerados proceduralmente** via Web Audio API (sem arquivos externos)
- **Painel Analytics** com streak, total de sessões, gráfico semanal e histórico
- **Configurações personalizáveis**: duração do foco, pausa e meta diária
- Dados salvos no **localStorage**
